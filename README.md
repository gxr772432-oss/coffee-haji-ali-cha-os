# كوفي حجي علي — CHA OS

تطبيق ويب عربي شخصي لإدارة المهام والمشاريع والملاحظات والمالية ومسودات المحتوى.

## ما يعمل في النسخة الحالية
- واجهة عربية RTL متجاوبة.
- مهام مع إكمال وحذف.
- مشاريع وملاحظات.
- تسجيل الإيرادات والمصروفات بالدينار العراقي.
- حفظ مسودات المحتوى.
- مساعد محلي محدود لإضافة مهمة وعرض عدد المهام.
- حفظ تلقائي في المتصفح، وتصدير/استيراد JSON.
- PWA manifest وService Worker لتخزين ملفات الواجهة بعد أول زيارة عبر HTTPS.

## حدود النسخة
لا يوجد حتى الآن نموذج ذكاء اصطناعي متصل أو حسابات مستخدمين أو مزامنة سحابية أو قاعدة بيانات مشتركة أو جدولة خلفية أو نشر فعلي إلى منصات التواصل. مسودات المحتوى لا تُنشر تلقائياً. البيانات الحالية محفوظة في متصفح الجهاز وقد تُفقد عند مسح بياناته؛ احتفظ بنسخة احتياطية.

## النشر
ملف GitHub Actions في `.github/workflows/pages.yml` ينشر الموقع إلى GitHub Pages عند الدفع إلى main. قد تحتاج إلى اختيار GitHub Actions كمصدر في Settings > Pages. لا تعتبر الخدمة منشورة حتى ينجح workflow ويظهر رابط Pages.

لا تضع كلمات مرور أو مفاتيح API في هذا المستودع.
