# كوفي حجي علي — CHA OS

مساحة عمل رقمية شخصية بواجهة عربية RTL، مصممة للهاتف أولاً.

## حالة المشروع
نسخة تأسيسية قيد البناء. ستضاف وظائف التطبيق تدريجياً مع اختبارها قبل إعلان جاهزيتها.

## مبادئ المشروع
- واجهة عربية متجاوبة.
- حفظ محلي ونسخ احتياطي في المرحلة الأولى.
- لا تُخزّن مفاتيح API أو كلمات المرور داخل المستودع.
- الذكاء الاصطناعي والمزامنة السحابية والنشر الاجتماعي تتطلب تكاملات مستقلة وتفويضاً رسمياً.
